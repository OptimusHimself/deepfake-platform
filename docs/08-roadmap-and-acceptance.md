## 5. P3 · 图片检测与红框

> **已提前落地：音频检测（`detect.audio`）**
> - 模型可选：`spectra-aasist3`（推荐，多语言）、`xlsr-asvspoof`（更快，英文为主）、`auto`
> - 4 秒窗口 / 1 秒步长；返回 fake 概率、判定、置信度、时间线片段、模型警告
> - 实测：用户真实中文 0% fake；Qwen 克隆中文 99.98%、英文 97%（Spectra）；XLS-R 对中文克隆 82%、英文克隆 10%
> - 代码：`server/detector.py`、`server/app.py`、`app/src/DetectionPanel.tsx`

**范围**
- 视觉服务：SCRFD + EffNet-B4 + CLIP 线性探针 + Grad-CAM + 连通域 + 叠加图。
- 报告 schema、模型投票、警告、CPU 降级。
- 内部演示集（30 真 / 30 假）与评估脚本。

**退出标准**
- [ ] 上传平台生成的换脸图，返回 `fake` 概率 ≥0.7，红框落在人脸/五官附近，叠加图可直接展示。
- [ ] 上传本人真实照片，误报率 ≤10%；低置信时返回 `uncertain` 而不是强行判定。
- [ ] 无人脸图片走 patch 兜底并带警告；多人脸图片逐脸检测。
- [ ] 单图端到端 <3s（GPU），报告字段与 [02 §7](02-api-contracts.md#7-检测报告) 完全一致。
- [ ] 删除红框区域后 fake 分数明显下降（删除/插入 sanity test 通过）。
- [ ] 评估：AUC ≥0.90、EER ≤10%（演示集，允许样本量小）。

## 6. P4 · 视频生成（唇形 / 换脸）

> **2026-10-31 先落地图片换脸（用户确认 B/A/A/A）**
> - 模型：默认 **HyperSwap 1a 256**（FaceFusion 3.3，2025，ResearchRAIL）；保留 **inswapper_128**（2023）作 legacy 对照
> - 任务：`image.face_swap`；源脸图 + 目标图；目标多人脸默认最大脸
> - 实测：HyperSwap 预热后 **0.122s/张**，首张约 10s；inswapper 预热后约 0.145s/张
> - 图片检测与图片防御已配套；视频换脸按原计划后置

**范围**
- 先接 MuseTalk（standard）做 `video.lipsync` 与 `video.talking_head`（TTS 串联）。
- 再接换脸（inswapper 或 SimSwap）做 `video.face_swap`；组合任务 `video.face_swap_lipsync`。
- ffmpeg 统一封装、进度三段、时长/分辨率限制。

**退出标准**
- [ ] 10s 720p 视频改口型 <5min（4090/L20 实测回填）；口型与音频基本对齐。
- [ ] 换脸视频人脸稳定、无明显闪烁；多人脸默认最大脸并提示。
- [ ] 图 + 文 → 说话视频全链路成功（TTS 中间产物可追踪）。
- [ ] 无脸/超长/显存不足分别有明确错误与降档建议。
- [ ] 产物浏览器可播放（H.264/AAC/faststart），音频不丢。

## 7. P5 · 主动防御

> **2026-10-31 先落地图片防御基线（用户确认）**
> - 方法：CLIP ViT-B/32 PGD + DwtDctSvd 水印 + HMAC-SHA256 证书
> - 实测（550×550 medium）：PSNR **40.87dB**、SSIM **0.9802**、水印解码成功
> - **重要**：旧版 CLIP 全局扰动未针对换脸身份编码器，实际保护有限；此前“0.898→0”测试有误，已撤回
> - 升级：SGD-Guard（IJCAI 2026）/ NullSwap（ICCV 2025）+ TrustMark；音频/视频防御后置

**范围**
- 图片：CLIP + ArcFace 代理、PGD + EOT、DwtDctSvd 水印、指标与换脸验证。
- 音频：ECAPA 代理、SNR/PESQ 约束、AudioSeal、克隆相似度验证。
- 证书、HMAC、`/v1/defense/verify`、前后对比 UI。

**退出标准**
- [ ] 中档图片：PSNR ≥40dB、SSIM ≥0.98；换脸身份相似度下降 ≥0.15。
- [ ] 中档音频：SNR ≥20dB、PESQ ≥3.5；克隆相似度下降 ≥0.10。
- [ ] 水印：原文件位准确率 ≥99%；JPEG q90 / MP3 128k 后 ≥90%。
- [ ] 验证接口对篡改文件返回 `HASH_MISMATCH`，对未知证书返回 `CERT_UNKNOWN`。
- [ ] UI 明确展示“不保证免疫”，并保留原件。

## 10. 风险与缓解

| 风险 | 影响 | 缓解 |
|---|---|---|
| 模型许可证限制（换脸/唇形/水印） | 不能商用或不能公开演示 | P4 前逐个核实；非商用模型只做本地演示；准备可商用替代 |
| Qwen3-TTS 对防御扰动不敏感 | 防御指标达不到 | P5 先实测，必要时换代理/加目标攻击；文档不承诺具体数值 |
| 检测器跨生成器泛化差 | 新模型生成的假图漏检 | 用平台自己的生成器造评估集；集成 + 校准；明确局限 |
| AutoDL 无公网端口/隧道不稳 | 演示中断 | 默认隧道 + 重连；准备 6006 备选；离线 mock 兜底 |
| 24GB 跑不动视频 | P4 延期 | 先 512/720p；P4 升 48GB |
| 大文件上传失败 | 体验差 | 限制 + 重试 + 进度；P6 断点续传 |
| 范围膨胀（账号/多用户/公网） | 迟迟不能演示 | 明确非目标；P0–P6 外的新需求进 backlog |
| 滥用风险 | 伦理/法律风险 | 同意门、仅本人素材、水印、清单、非公开部署 |

## 12. 文档批准后的立即行动

1. 你 review 本套文档，重点确认：任务矩阵、Qwen3-TTS 路由、检测红框定义、防御边界。

## 13. Definition of Done

一个阶段算完成，必须同时满足：

- 功能按验收清单通过；
- 错误路径有明确错误码与 UI 文案；
- 文档（接口、模型、部署、指标）同步更新；
- 没有新增未登记的端口、任务 ID、角色或错误码；
- 本地与远端都能一键清理演示数据；
- 你知道“下一步做什么、为什么”。

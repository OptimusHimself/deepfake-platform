# 06 · UI/UX：页面、状态与文案

> **当前实现（2026-10-31）**：本地网页已有五个页签：音频克隆、图片换脸、音频检测、图片检测、主动防御。图片换脸支持源脸/目标图；图片检测支持整脸框 + top-2 区域 + 热图；防御支持低/中/高强度、PSNR/SSIM/水印/证书。视频与音频防御仍是后续设计。

## 1. 设计原则

- **一屏完成一件事**：生成、检测、防御各自一页，不堆功能。
- **输入即提示**：每个上传框写明“要什么、多久、什么格式”，缺什么直接标红。
- **自动但有解释**：默认 `auto` 选模型，但显示“将使用哪个模型、为什么”，允许高级用户指定。
- **结论不夸大**：检测页固定展示“非鉴定结论”；防御页固定展示“不保证免疫”。
- **本地感**：所有文件、任务、结果都在“我的资产库”，随时可删。
- **中文优先**：术语中文化，模型名保留英文（Qwen3-TTS、MuseTalk 等）。

视觉：浅色主题、白底卡片、单一强调色（靛蓝 `#4F46E5`）、圆角 12px、留白充足；桌面优先（≥1280px），1024px 可用；不做花哨动画，只保留进度与淡入。

## 2. 信息架构

```
/                      → 重定向 /generate
/generate              生成
  /generate?job=<id>   生成任务详情
/detect                检测
  /detect?job=<id>     检测结果
/defend                主动防御
  /defend?job=<id>     防御结果
/library               资产库（上传/生成/检测报告/证书）
/settings              设置（远端、存储、同意记录、关于）
```

左侧固定导航（宽 220px），顶部显示远端状态点 + 队列数。导航项：生成、检测、主动防御、资产库、设置。

## 3. 生成页

### 3.1 布局

```
┌──────────────┬──────────────────────────────────────────────────────┐
│ 生成          │  ① 选择模式                                          │
│ 检测          │  [音频克隆] [文字转语音] [说话视频] [换脸] [改口型]   │
│ 主动防御      │  ─────────────────────────────────────────────────   │
│ 资产库        │  ② 输入                                              │
│ 设置          │  ┌ 参考音频 ┐ 拖入或点击；3–30s，wav/mp3/m4a          │
│              │  └──────────┘                                       │
│              │  参考文本 [____________________________________]      │
│              │  目标文本 [____________________________________]      │
│              │  语言 [中文 ▾]   质量 [高 ▾]   随机种子 [42]         │
│              │  ─────────────────────────────────────────────────   │
│              │  将使用：Qwen3-TTS 1.7B Base（自动）  ⓘ 为什么        │
│              │  [ 开始生成 ]                                        │
│              │  ③ 队列 / 结果                                       │
└──────────────┴──────────────────────────────────────────────────────┘
```

### 3.2 模式卡

| 模式 | 显示名 | 一句话 |
|---|---|---|
| `audio.clone` | 音频克隆 | 用我的声音说新的话 |
| `audio.tts` | 文字转语音 | 选一个音色朗读文本 |
| `video.talking_head` | 照片说话 | 一张正脸照 + 文本 → 视频 |
| `video.lipsync` | 视频改口型 | 让视频里的人对上新区音频 |
| `video.face_swap` | 视频换脸 | 把视频里的脸换成我的 |
| `video.face_swap_lipsync` | 换脸 + 配音 | 换脸并改口型 |
| `video.talking_head_audio` | 照片说话（音频驱动） | 照片 + 音频 → 视频 |

### 3.3 动态表单

按所选 task 渲染字段，字段定义来自能力清单：

- 文件角色 → 上传框；`required_inputs` 标红星。
- `text` 字段 → 单行/多行输入；`required_text` 标红星。
- `options.language` → 下拉（能力清单 languages）。
- `quality` → 快速/标准/高。
- `strength` 只在防御页出现。
- 文本字段下方给出示例，尤其是参考文本 vs 目标文本的区别。

### 3.4 提交后

- 立即插入“任务队列”卡片：状态徽章、进度条、阶段文案、已用时间。
- `queued`：显示排队位置或“等待 GPU”。
- `running`：阶段（合成中 / 唇形中 / 封装中）+ 进度；可取消。
- `succeeded`：播放器（音频波形或视频播放器）+ 下载 + 保存到本地 + “用此结果去检测”。
- `failed`：错误卡（code、message、hint、重试/换输入）。
- 提交按钮在请求中禁用，防重复；使用幂等键。

### 3.5 路由解释

点击“为什么”展开：

```
任务：音频克隆
选中：Qwen3-TTS 1.7B Base
原因：reference_audio + reference_text + target_text 齐全；
     模型 ready，优先级 100；quality=high 优先 1.7B。
其他候选：Qwen3-TTS 0.6B Base（质量档较低，未选）
```

## 4. 检测页

### 4.1 输入

```
┌────────────────────────────────────────────────────────────┐
│  拖入图片 / 视频 / 音频，或点击选择                          │
│  支持 jpg/png/webp、mp4/mov、wav/mp3/m4a；单文件 ≤500MB     │
│  ⚠ 仅分析本人或已授权素材                                    │
└────────────────────────────────────────────────────────────┘
```

- 上传后自动识别模态并提交，不需要用户选“这是图片还是视频”。
- 识别失败时显示“无法识别文件类型”，给支持列表。

### 4.2 结果页

```
┌───────────────┬──────────────────────────────────────────────┐
│ 判定           │  [叠加图 / 原始图 / 热力图] 切换               │
│  FAKE  93%    │  ┌────────────────────────────────────────┐  │
│  ▓▓▓▓▓▓▓▓░    │  │        （红框 + 热力图叠加）             │  │
│  阈值 50%     │  └────────────────────────────────────────┘  │
│  置信度 高     │  区域列表：                                   │
│               │  ① face_boundary 0.91  [定位]                 │
│  模型投票      │  ② mouth_region 0.78   [定位]                 │
│  EffNet 0.95  │  ─────────────────────────────────────────   │
│  CLIP   0.90  │  ⚠ 检测分数不是司法鉴定结论…                  │
│               │  [导出 JSON] [导出标注图] [用此结果做防御]     │
└───────────────┴──────────────────────────────────────────────┘
```

视频：上方播放器，下方时间轴；可疑片段用红色区间，拖动显示该采样帧的框。
音频：波形 + 红色可疑区间；点击区间播放。

### 4.3 状态文案

| 状态 | 文案 |
|---|---|
| 上传中 | 正在上传… 42% |
| 排队 | 等待检测… |
| 运行 | 正在分析人脸 / 抽帧 / 音频窗口… |
| 成功 | 分析完成 |
| 无人脸 | 未检测到人脸，已按图像 patch 分析（结果置信度较低） |
| 失败 | 无法分析该文件（原因 + 建议） |

## 5. 主动防御页

```
┌───────────────┬──────────────────────────────────────────────┐
│ ① 上传素材     │  ┌ 我的照片 ┐  或  ┌ 我的录音 ┐               │
│               │  └──────────┘      └──────────┘               │
│ ② 保护强度     │  (•) 低  ≥42dB / ≥25dB SNR                    │
│               │  ( ) 中  ≥40dB / ≥20dB SNR  推荐               │
│               │  ( ) 高  ≥36dB / ≥15dB SNR  可能可见/可听       │
│ ③ 开始保护     │  [ 生成保护版本 ]                             │
│               │  ─────────────────────────────────────────    │
│ ④ 结果         │  前后对比滑块 | PSNR 41.2 | SSIM 0.987        │
│               │  身份相似度 0.78 → 0.41 | 水印 已嵌入           │
│               │  [下载保护文件] [下载证书] [验证]               │
│               │  ⚠ 不保证抵御压缩、裁剪、重录与自适应攻击        │
└───────────────┴──────────────────────────────────────────────┘
```

- 上传后显示“这是本人/已授权素材”的确认；未确认不能提交。
- 保护中显示阶段：人脸对齐 → 扰动优化 → 水印 → 指标评估。
- 结果必须同时展示“画质指标”和“相似度下降”，否则用户只看到“成功”会误解。
- 验证入口：上传保护文件 → 显示 valid/原因/watermark_id/签发时间。

## 6. 资产库

- 顶部筛选：全部 / 上传 / 生成 / 检测报告 / 保护文件。
- 列表或网格：缩略图、类型图标、名称（原文件名或“音频克隆 · job_xxx”）、模型、大小、时间、状态。
- 操作：预览、下载、保存到本地、用此结果检测/防御、删除。
- 多选删除；删除前确认“本地与远端缓存都会清理”。
- 空状态：“还没有资产，去生成或检测一个吧”。

## 7. 设置

| 分区 | 内容 |
|---|---|
| 远端连接 | base URL、Token（写入后不回显）、连接测试、当前状态、延迟 |
| SSH 隧道 | 展示可复制的命令、说明“先运行隧道再测试”；端口 18000 |
| 生成/检测 | 默认语言、默认质量、检测阈值（0.4/0.5/0.6）、是否启用 ASR 补全 |
| 存储 | 本地占用、远端占用、产物保留天数、清理按钮 |
| 同意记录 | 时间、素材哈希、用途、删除 |
| 关于 | 版本、模型清单、许可证、免责声明 |

## 8. 组件清单

- `AppShell`：侧边导航、远端状态、队列徽章。
- `UploadDropzone`：拖拽、点击、进度、错误、文件卡片、预览。
- `TaskForm`：按能力清单动态渲染角色/文本/选项。
- `ModelBadge`：自动/手动模型 + 路由原因 popover。
- `JobCard` / `JobQueue`：状态、进度、阶段、取消、重试。
- `ResultPlayer`：音频波形 / 视频播放器 / 图片查看器。
- `VerdictGauge`：分数、阈值刻度、置信度。
- `RegionOverlay`：叠加图 + 框列表联动。
- `Timeline`：视频/音频片段。
- `ModelVotes`：分数条与权重。
- `DefenseCompare`：前后滑块 + 指标卡。
- `ErrorCard`：code/message/hint/actions。
- `EmptyState`、`Toast`、`ConfirmDialog`。

## 9. 状态与错误

- 全局横幅：远端离线/隧道断开/Token 无效；提供“重试”和“打开设置”。
- 上传：类型不符立即提示；超限提示具体上限；中断可重传。
- 表单：必填缺失时禁用提交并显示“还缺：参考文本”；不做提交后报错。
- 任务：超时/取消/失败都有明确下一步；`NO_CAPABILITY` 展示缺失角色和可替代任务按钮。
- 删除：二次确认；删除中禁用操作。
- 离线：允许浏览本地资产库，禁止新建任务。

## 10. 文案规范

- 按钮用动词：“开始生成”“开始检测”“生成保护版本”“保存到本地”。
- 不用“Deepfake 检测器认为 100% 假”；用“模型判断：偏假（93%）”。
- 固定免责声明：
  - 检测：“检测结果由模型给出，不是司法鉴定，也不能单独作为指控依据。”
  - 防御：“保护能提高未授权生成的成本，但不能保证完全阻止。”
- 错误提示必须包含“发生了什么 + 你可以做什么”。

## 11. 可访问性与细节

- 所有上传框支持键盘操作；焦点环可见。
- 颜色对比度 ≥4.5:1；不仅靠颜色表达真假（同时用文字/图标）。
- 图片有 alt；视频有字幕/说明；音频有波形和文字摘要。
- 进度用 `aria-live` 播报关键状态。
- 离开运行中页面不丢任务；任务在全局队列继续。

## 12. 3 分钟演示脚本

1. 生成页 → 音频克隆 → 上传自己的参考音频 + 填参考文本/目标文本 → 生成 → 播放。
2. 结果卡点“用此结果去检测” → 检测页显示概率与（对视频/图片）红框。
3. 检测页再上传一张平台生成的换脸图 → 展示红框与模型投票。
4. 防御页 → 上传自己的照片 → 中档 → 生成保护版 → 展示 PSNR/相似度下降 → 验证水印。
5. 设置页 → 展示远端健康、SSH 隧道命令、队列与存储。
